--------------------------------------------------------------------------------
1. API TYPES USED
--------------------------------------------------------------------------------
The game uses four kinds of external services:

  TYPE                         SERVICE                              USED FOR
  ---------------------------  -----------------------------------  ------------------------------
  RESTful API                  Firebase Realtime Database           Player data, decks, store,
                                                                    leaderboard, matchmaking,
                                                                    achievements
  RESTful API                  Brevo Transactional Email            Registration verification codes
  RPC-style HTTP API           Firebase Identity Toolkit            Signup, login, account delete
  OAuth 2.0 API                Google OAuth 2.0                     Sign in with Google
  OAuth 2.0 API                Google Secure Token API              Refresh Firebase ID tokens
  Web pages (not an API)       thehackslash.com                     Forgot-password and website

There is no real-money payment API. The in-game store spends datapoints and
saves the result to the Firebase Realtime Database RESTful API.

2. RESTFUL APIS
--------------------------------------------------------------------------------

2.1 Firebase Realtime Database REST API
    Type:        RESTful API
    Base URL:    https://hackslash---ccg-default-rtdb.firebaseio.com/
    Project ID:  hackslash---ccg
    Auth domain: hackslash---ccg.firebaseapp.com
    Addon:       addons/godot-firebase
    Autoload:    Firebase (project.godot)
    Helper:      Scripts/UserData.gd

    Resource URLs + HTTP methods + JSON. Stateless calls use ?auth={idToken}.

      GET     read a resource
      PUT     create or fully replace a resource
      PATCH   partially update a resource
      DELETE  remove a resource

    REST URL pattern:
      {FIREBASE_DB_URL}{path}.json?auth={idToken}

    Central helper methods:
      make_authenticated_get_request(path)
      make_authenticated_patch_request(path, data)
      make_authenticated_put_request(path, data_string)
      make_authenticated_delete_request(path)

    REST resources:

    /users/
      Player profiles, keyed by Firebase Auth UID.

      GET    /users.json
             Leaderboard dump; also used to load all users for matchmaking
             Scenes/leaderboard.gd, Scripts/UserData.gd

      GET    /users.json?orderBy="email"&equalTo="{email}"
             Check if an email is already registered
             Scripts/login_logic.gd, Scripts/register_logic.gd

      GET    /users.json?orderBy="{rankField}"&startAt={min}&endAt={max}&auth={token}
             Rank-range query for matchmaking opponents
             Scenes/MatchmakerController.gd

      GET    /users/{uid}.json
      PATCH  /users/{uid}.json
             Load / update a profile (playtime, datapoints, cards, rank,
             XP/level, in-game name, online status, campaign, etc.)
             Scripts/UserData.gd
             Scripts/login_logic.gd
             Scripts/register_logic.gd
             Scripts/change_profile.gd
             Scripts/home_screen_animator.gd
             Scripts/achievements_controller.gd
             Scripts/MatchStatsController.gd
             Scripts/profile_preview.gd
             Scenes/StoreController.gd
             Scenes/MatchmakerController.gd
             Scenes/TutorialManager.gd

      GET    /users/{uid}/decks.json
      GET    /users/{uid}/decks/{deckId}.json
      PUT    /users/{uid}/decks/{deckId}.json
      DELETE /users/{uid}/decks/{deckId}.json
             Player-owned decks
             Scripts/UserData.gd
             Scripts/collections_scene_controller.gd
             Scripts/collections_screen_controller.gd

      GET    /users/{uid}/deck_count.json
      PUT    /users/{uid}/deck_count.json
             How many decks the player has
             Scripts/collections_scene_controller.gd
             Scripts/collections_screen_controller.gd

      GET    /users/{uid}/Avatars.json
             Owned / selected profile pictures
             Scripts/change_profile.gd

      PATCH  /users/{uid}/achievements.json
             Achievement flags
             Scripts/achievements_controller.gd
             Scripts/achievement_unlocker.gd

    /usernames/
      GET    /usernames/{username}.json
             Unique username check
             Scripts/login_logic.gd, Scripts/register_logic.gd

    /public_decks/
      GET    /public_decks/{deckId}.json
      PUT    /public_decks/{deckId}.json
      DELETE /public_decks/{deckId}.json
             Shareable / importable decks
             Scripts/collections_scene_controller.gd
             Scripts/collections_screen_controller.gd

    /card_stats/
      GET    /card_stats.json
      GET    /card_stats/{deckId}.json
      PUT    /card_stats/{deckId}.json
      PATCH  /card_stats/{deckId}.json
      PUT    /card_stats/{cardId}/card_used.json
             Historical deck stats and per-card usage
             Scripts/UserData.gd
             Scripts/collections_scene_controller.gd
             Scripts/collections_screen_controller.gd
             Scripts/MatchStatsController.gd

    /achieveProgress/
      GET    /achieveProgress/total_players.json
      PUT    /achieveProgress/total_players.json
             Global player count, incremented on registration
             Scripts/register_logic.gd

      PATCH  /achieveProgress/unlocked_counts/{key}
             Achievement unlock counts
             Scripts/achievement_unlocker.gd

    Root multi-path write
      PATCH  /.json?auth={token}
             Atomic create of users/{uid} + usernames/{username} on signup
             Scripts/register_logic.gd


2.2 Brevo Transactional Email REST API
    Type:      RESTful API
    Endpoint:  POST https://api.brevo.com/v3/smtp/email
    File:      Scripts/register_logic.gd
    Sender:    thehackslash@gmail.com  (display name: HackSlash)

    POST creates an email-send resource. Success is HTTP 201 Created.

    Used to email a 6-digit verification code during registration.

    Headers:
      Content-Type: application/json
      Accept:       application/json
      api-key:      {BREVO_API_KEY}

3. RPC-STYLE HTTP APIS
--------------------------------------------------------------------------------
Not RESTful. Endpoints are named actions, almost always POST.

3.1 Firebase Identity Toolkit
    Type:      RPC-style HTTP API
    Base URL:  https://identitytoolkit.googleapis.com/v1/
    Addon:     addons/godot-firebase/auth/auth.gd

    POST .../accounts:signUp?key={API_KEY}
         Email/password registration
         Scripts/register_logic.gd
         (Firebase.Auth.signup_with_email_and_password)

    POST .../accounts:signInWithPassword?key={API_KEY}
         Email/password login
         Scripts/login_logic.gd
         (Firebase.Auth.login_with_email_and_password)

    POST .../accounts:signInWithIdp?key={API_KEY}
         Google Sign-In after an OAuth token is obtained
         Scripts/login_logic.gd, Scripts/register_logic.gd
         (Firebase.Auth.get_GoogleProvider + get_auth_localhost on port 8060)

    POST .../accounts:delete?key={API_KEY}
         Deletes a temporary Auth user after a failed / incomplete Google signup
         Scripts/login_logic.gd, Scripts/register_logic.gd


--------------------------------------------------------------------------------
4. OAUTH 2.0 APIS
--------------------------------------------------------------------------------
Not RESTful. Login and token protocol, not resource CRUD.

4.1 Google OAuth 2.0
    Type:       OAuth 2.0 API
    Authorize:  https://accounts.google.com/o/oauth2/v2/auth
    Token:      https://oauth2.googleapis.com/token
    Provider:   addons/godot-firebase/auth/providers/google.gd
    Used from:  login and register screens
    Redirect:   localhost:8060

    Sign in with Google.

4.2 Google Secure Token API
    Type:      OAuth 2.0 API
    Endpoint:  POST https://securetoken.googleapis.com/v1/token?key={API_KEY}
    Body:      grant_type=refresh_token&refresh_token={refreshToken}
    File:      Scripts/UserData.gd  (refresh_id_token)

    Refreshes the Firebase ID token when a Realtime Database call returns
    HTTP 401.
